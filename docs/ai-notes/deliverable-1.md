# Deliverable 1 – AI Notes

## Project
**Pharmacy Inventory and Sales Management System**

---

## AI Tool Used
- ChatGPT (OpenAI)

---

## Prompt 1

**Prompt:**
Review our Pharmacy Inventory and Sales Management System backlog. Check if every record type has complete CRUD operations and identify any missing user stories or screen states.

### AI Response Summary
The AI reviewed the backlog and confirmed that every primary record type (Medicines, Suppliers, Customers, and Sales) should include the following user stories:

- Create
- Read (List View)
- Read (Detail View)
- Update
- Delete

The AI also suggested including the following screen states:

- Login Screen
- Dashboard
- List Screens
- Detail Screens
- Create Form
- Edit Form
- Delete Confirmation
- Empty State
- Error State

### Decision
We accepted these suggestions because they complete the CRUD functionality and ensure that every screen required by the project is represented.

---

## Prompt 2

**Prompt:**
Is the scope of our Pharmacy Inventory and Sales Management System realistic for a team of five students to complete within ten weeks? If not, what features should be removed?

### AI Response Summary
The AI determined that the project scope is realistic if it focuses on the core modules:

- Medicine Management
- Supplier Management
- Customer Management
- Sales Management
- Inventory Tracking

The AI recommended postponing advanced features such as:

- Barcode scanning
- Online ordering
- SMS notifications
- Email notifications
- Mobile application
- Sales analytics and forecasting
- Multi-branch pharmacy support
- Prescription image recognition

### Decision
We accepted the recommendation to focus only on the core features. Advanced features will not be included in this project to keep the scope manageable within the available time.

---

## Prompt 3

**Prompt:**
Review our planned wireframes and identify any missing screens that are commonly required for a CRUD-based Pharmacy Inventory and Sales Management System.

### AI Response Summary
The AI suggested including the following screens:

- Login
- Dashboard
- Medicines
- Medicine Details
- Add Medicine
- Edit Medicine
- Suppliers
- Customers
- Sales
- Sale Details
- Delete Confirmation
- Empty State
- Error State

### Decision
We accepted these suggestions because they match the project requirements and provide complete coverage of all user stories.

---

## Summary

AI was used only as a planning and review tool during Deliverable 1. It helped the team:

- Verify that all CRUD operations were included.
- Identify missing screens and application states.
- Review the project scope for feasibility.
- Suggest improvements to the backlog and wireframes.

The team reviewed all AI suggestions and decided which recommendations to accept. Final project decisions were made by the team.
